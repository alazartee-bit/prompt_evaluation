Task: Write a Python function that takes an S3 bucket name and returns a list of all object keys in the bucket using boto3, handling pagination.

Model score: 9/10   Syntax score: 10/10

Grader: The answer meets both criteria: it uses a paginator and returns a list of key strings. It also handles empty buckets correctly. Only minor extras such as error handling and flexibility are missing.

Weaknesses: No error handling for missing buckets or access denied (not required by the task); Builds the full list in memory, which could be heavy for very large buckets; no generator option mentioned; Does not allow an injected client or a prefix parameter, which limits flexibility and testability

```python
import boto3


def list_s3_object_keys(bucket_name):
    """Return a list of all object keys in the given S3 bucket.

    Uses the list_objects_v2 paginator so buckets with more than
    1,000 objects are fully listed.
    """
    s3 = boto3.client("s3")
    paginator = s3.get_paginator("list_objects_v2")
    keys = []
    for page in paginator.paginate(Bucket=bucket_name):
        for obj in page.get("Contents", []):
            keys.append(obj["Key"])
    return keys
```

The `list_objects_v2` paginator handles continuation tokens automatically, so listings beyond 1,000 keys are complete. Using `page.get("Contents", [])` keeps empty buckets from raising a `KeyError`.

Task: Write a Python function that sends a message string to an SQS queue given its queue URL and returns the MessageId.

Model score: 9/10   Syntax score: 10/10

Grader: The answer meets both criteria: it calls send_message with QueueUrl and MessageBody and returns MessageId. The minor weaknesses are the per-call client creation and the lack of FIFO support in the signature.

Weaknesses: Creates a new boto3 client on every call, which is inefficient and offers no way to inject a client or region for testing; No input validation or explicit error handling, though propagating the error is documented and reasonable; The FIFO note is only prose; the function has no optional parameters to support FIFO queues

```python
import boto3


def send_sqs_message(queue_url: str, message: str) -> str:
    """Send a message string to an SQS queue and return its MessageId.

    Args:
        queue_url: The URL of the target SQS queue.
        message: The message body to send.

    Returns:
        The MessageId assigned by SQS.

    Raises:
        botocore.exceptions.ClientError: If SQS rejects the request.
    """
    sqs = boto3.client("sqs")
    response = sqs.send_message(QueueUrl=queue_url, MessageBody=message)
    return response["MessageId"]
```

The function calls `send_message` with `QueueUrl` and `MessageBody` and returns `MessageId` from the response. Errors propagate as `ClientError` so the caller can handle them. For FIFO queues, you would also need to pass `MessageGroupId`.
